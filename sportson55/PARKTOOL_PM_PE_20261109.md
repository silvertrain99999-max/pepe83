### 파크툴 재고 운영 기준

- SPORTS55 본사 주문 가능: 온라인 수량 20개.
- 본사 품절: 확인된 매장 재고를 적용.
- 본사·매장 모두 없음: 0개.
- 본사 미검색, 모델·포장·규격 불일치, 사용자 보류 상품은 추정 변경하지 않는다.
- 이 기준은 파크툴 운영 기준이다. 다른 공급사의 5·3·0 규칙과 혼용하거나 본사 실수량으로 해석하지 않는다.
- 가격은 소비자가 기준으로 대조하고 기존 할인율·금액·기간·조건을 유지한다.
- 옵션 합계는 개별 규격 수량의 합계로 판단한다. TAP-20처럼 복수 옵션에 재고가 있으면 상품 합계가 20개를 넘을 수 있다.
- 스마트스토어는 재고 0에 따른 품절과 판매중지를 구분하고 진열 상태를 유지한다.
- 재입고 옵션은 수량뿐 아니라 옵션 사용·판매 가능 상태도 확인한다.
- 매장 재고 원본은 이번 작업에서 변경하지 않았다.

### 파크툴 상품명 만드는 기준

**브랜드 + 정확한 모델번호 + 공구명·용도 + 필요한 규격·구성**

1. 모델번호의 하이픈·소수점·세대 구분을 보존한다.
2. 확인된 공구명, 호환 규격, 포장·판매 단위를 유지한다.
3. 이번 승인 범위에서 '초특가', 중복 PARKTOOL, 별표, 불필요한 밑줄을 정리했다. 실제 프로모션·구성의 의미를 바꾸는 문구는 자동 제거하지 않는다.
4. 스마트스토어는 기본 상품명 외에 **전용 상품명 사용 여부와 실제 전용명**을 반드시 확인한다. 기본 상품명만 바꿔도 전용명은 남을 수 있다.
5. 색상·사이즈·호환성·단종 여부를 상품명만 보고 추정하지 않는다.
6. 카페24 모델명은 일반 브랜드명 대신 정확한 공구 모델로 보완했다. 실제 모델이 바뀐 것은 아니다.
7. 브랜드·카탈로그·상품속성 재구성은 이번 검색정보 보완에서 수행하지 않았다.

### 검색 설명 기준

- 상품별 모델·용도·규격 확인에 도움이 되는 내용으로 작성한다.
- 관련 없는 브랜드 나열이나 과거 매장 공통 설명을 그대로 재사용하지 않는다.

- TS-4.3 상품명에는 빠진 '파크툴'을 추가했다.
- 가격·재고·배송·사은품·미확인 호환성을 SEO 문구로 임의 변경하거나 보장하지 않는다.
- '구매 시 니트릴 장갑 1쌍(2개) 증정' 사은품 설정은 유지했다.

## 3. 검증과 중단 복구

### 검증 기준

- 카페24 223상품은 재열람한 상품명·모델명·제목·설명·키워드를 작업안과 대조했다. 가격·수량 변화 없음.
- 스마트스토어 311상품 최종 내려받기와 TS-4.3 별도 내려받기로 가격·재고·판매상태·사은품 등 보호값을 확인했다.
- 전용 상품명 86건은 최종 내려받은 실제 값과 수정안 불일치 0건.
- 마지막 공통 설명 5건은 상품수정 완료 안내를 확인했다. 이 최종 보완은 전체 목록 내려받기 이후 수행된 텍스트 수정이며, 모두 재다운로드 검증했다고 기록하지 않는다.
- 상세 옵션별 가격 전체를 이번 PE에서 다시 대조한 것은 아니다. 옵션 사용 여부 등 목록 필드 확인과 옵션별 상세 검증을 구분한다.
- 저장 완료는 검색엔진 반영 완료·플랫폼 승인·순위 상승을 의미하지 않는다.

### 연결 문제 대응

1. 상품 ID와 현재 화면의 모델을 먼저 맞춘다.
2. 저장 클릭만으로 완료 처리하지 않는다. 완료 안내·재열람·내려받기 중 확인 근거를 기록한다.
3. 화면값과 자동 읽기값이 다르면 해당 구간을 완료 집계에서 제외하고 실제 화면으로 다시 확인한다.
4. 미저장 입력이 있으면 새로고침하지 않는다. 저장 여부부터 해결한다.
5. 반복되는 목록 이동·저장 장애에는 현재 상품·입력 여부·마지막 확인 지점을 기록한다.
6. 사용자 재오픈 후 이미 완료한 작업을 중복 적용하지 않고 마지막 미확인 지점부터 복구한다.
7. 수정 중 보호 항목 차이가 발견되면 원인 확인 전 완료로 처리하지 않는다.
