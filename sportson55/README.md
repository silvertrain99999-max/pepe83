# SPORTS55 상품관리 코드

Park Tool 및 Finish Line의 오프라인 변경안 생성기입니다. 실제 쇼핑몰 접속·입력·저장 기능은 포함하지 않습니다.

## 규칙

- 본사 재고 있음: 온라인20개. 본사 품절: 확인된 매장 수량. 모두 없음:0개.
- 본사 미등록·매칭 불확실은 보류합니다. 최신 본사 정보와 실물 수량을 확인합니다.
- 기본 판매가는 본사 소비자가 기준이며 기존 할인율·금액·기간·조건을 유지합니다.
- 카페24 전체 품절은 판매가 대체문구 사용 및 `[품절]`. 일부 옵션만 품절이면 해당 옵션만0입니다.
- 상품명 별표 제거, 상품 삭제 없음. 사용자 보류 상품은 변경하지 않습니다.

## 파일

- `rules.py`: 파크툴 정확한 모델·포장 매칭 및 공통 가격·재고 변경안.
- `finish_line.py`: 제품군·제형·용량·단위 일치 확인, 동일 구성 묶음의 판매 단위 가격 환산, 전체 옵션 대응 확인.
- `test_rules.py`, `test_finish_line.py`: 18개 규칙 검증.

피니쉬라인의 g/ml, DOT/미네랄,120/240ml는 임의 환산·통합하지 않습니다. 혼합 묶음과 원단위 나머지가 있는 가격은 보류합니다. 옵션 총가격은 실제 기본가와 추가금으로 별도 대응해야 합니다.

```sh
# 저장소 루트에서 실행 (Python 3.10 이상, 외부 패키지 없음)
python -m unittest discover -s sportson55 -p "test_*.py" -v
```

```python
from sportson55.finish_line import package_price
assert package_price(168000, 12, 1) == 14000
```

브라우저 작업은 최신 화면에서 매칭·변경 전 값을 확인하고 저장 후 재조회합니다. 로그인은 사용자가 처리합니다. 매장 재고 원본·계정정보·작업 로그는 이번 코드 업로드에서 제외했습니다.

토픽은 별도 공급처와 할인·매장재고 규칙을 사용합니다. [토픽 운영 기준](../operations/README.md)을 참조하고 SPORTS5520개 규칙을 자동 적용하지 않습니다.
