# 토픽 상품관리 운영 기준

9월10~11일 사용자 점검을 토대로 만든 업무 규칙·실재고 목록·검토 계획 생성기입니다.
쇼핑몰 접속, 가격 저장, 연동 해제는 하지 않습니다. 외부 패키지와 로그인 정보가 필요 없습니다.

## 실행

Node.js22 이상에서:

```sh
npm test
npm run report
```

생성되는 reports/inventory.md는 재고표, inventory.json은 채널별 작업 상태입니다.
data/inventory.mjs는 실물 확인 당시 18종22개와 기존 작업 이력입니다. 현재 재고로 자동 사용하면 안 됩니다.

## 역할

|업무|담당|
|---|---|
|실물·신구형 최종 판단, 이미지·상세페이지 품질|형님|
|신규 업로드·삭제, 주문 후 수동 재고 차감|형님|
|카페24 할인 적용|형님|
|상품 대조, 소비자가·판매가·옵션·재고·품절·배송비 수정|아우|
|스토어팜 등 합의된 할인 설정|아우|
|실제 판매 화면 검증, 누락 기록, 허들 즉시 보고|아우|

## 업무 순서

1. 채널의 연동 여부·연동 항목·수정 기준을 확인합니다. 연동은 최소화하되 해제는 별도 작업입니다.
2. 하이랜더 공개 정보와 모델·품번·규격·정상가를 대조합니다. 유사 모델은 임의 연결하지 않습니다.
3. 카페24는 정상가 변경 시 소비자가와 판매가를 함께 관리합니다. 할인은 형님이 적용합니다.
4. 스토어팜은 옵션 추가금을 포함한 정상 구매금액을 기준으로 총20% 할인합니다. 기존 할인에 중복 가산하지 않습니다.
5. 마지막에 매장 실물을 확인합니다. 본사 품절과 별개로 매장 재고를 유지하고 대상 상품에 묶인 미보유 옵션은0·품절 처리합니다.
6. 이번 재고는 카페24·스토어팜 동일 수량, 주문 후 형님 수동 차감입니다. 쿠팡 조건은 아직 미확정입니다.
7. 매장 재고 배송비는 유료3,000원입니다. 할인 및 배송 조건은 채널별 판매 화면에서 검증합니다.
8. 저장→재조회→실제 판매 화면→연동 유지 상품은 다음 연동 후 유지 여부까지 확인합니다.
9. 막히면 즉시 중단·인계합니다. 완료한 항목/막힌 단계/사용자 처리 항목을 구분하며 같은 오류를 반복하지 않습니다.

## 완료와 미완료

- 스마트스토어15종 저장 이력이 있으나 에어로 웨지 팩 할인 미적용이 사용자 확인으로 보고됐습니다.
- 카페2414종 재고·배송비 저장 및 재조회 이력, 할인은 미적용·형님 담당입니다.
- 케이지마운트2는 사용자가 스토어팜 신규 업로드 완료를 보고했습니다. 상품번호·판매 조건은 미확인입니다.
- 일반 닌자+ 케이지마운트 모델 확인, 카페24 모듈라자바·에어태그 마운트 등록 확인, 스토어팜 RX EX레인커버 등록이 남아 있습니다.
- 사용자 전 상품 확인 완료 보고는 위 미적용 항목이 모두 해결됐다는 뜻으로 자동 해석하지 않습니다.
- 저장 성공만으로 verified를 기록하지 않습니다. 공급처 품절만으로 매장 재고를0으로 만들거나 임의5개를 입고하지 않습니다.
