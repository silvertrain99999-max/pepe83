## PM: 가격·재고·옵션 관리

- SCH-PM-01: 본사 **소비자가** 기준. 공급가로 판매가를 덮어쓰지 않는다. 옵션별 최종가격 = 기본판매가 + 옵션추가금으로 대조한다.
- SCH-PM-02: 사용자 승인값 **재고있음 5개 / 재고없음 0개**. 매장 재고 없음. 5개는 실제 본사 실수량이 아닌 온라인 운영 수량이다. 새 매장 재고가 생기면 반영 방식부터 확인한다.
- SCH-PM-03: 모델·등급·타입(TLR/TLE/튜브타입)·규격·색상을 모두 대조한다. 클래식스킨·브론즈·트랜스페어런트 스킨을 임의로 같은 옵션으로 간주하지 않는다.
- SCH-PM-04: 본사에서 못 찾은 상품은 품절이나 단종으로 단정하지 않고 보류한다. 보류가 자동 삭제 사유는 아니다.
- SCH-PM-05: 스마트스토어는 재고 0개여도 옵션 사용 Y와 전시를 유지하며 자동 품절 처리한다. 상품중지를 하지 않는다. 카페24는 이번 PM의 옵션 판매함/판매안함과 자동 품절 설정을 유지한다. 재고 회복 시 옵션 판매 여부도 확인한다.
- SCH-PM-06: 상품번호·옵션 조합·가격·수량의 변경 전후를 기록한다. 저장 안내와 재열람 일치를 구분한다.

## PE: 상품명 기준을 최우선으로

1. **슈발베 + 모델 + 확인된 등급/타입 + 용도 + 타이어** 순서로 작성한다. 여러 규격을 파는 상품은 상품명에 특정 규격만 넣지 않는다.
2. NEW·초특가·선수급·불필요한 기호·브랜드 반복을 정리한다. 사양이 확인되지 않은 엔듀런스·프로·에볼루션 등의 표현은 추가하지 않는다.
3. 카페24: 상품명, 검색어, 요약설명, Title, Author(YBBIKE), Description, Keywords, Alt. 상세 이미지·가격·할인·배송·옵션·재고는 보존한다.
4. 스마트스토어: 상품명, Page Title, Meta Description. 전용 상품명 사용 시 실제 노출명도 확인한다. 기존 태그는 검토해 유지하며 직접 관련 있는 태그만 추가한다. 이번 추가 태그는 G-ONE R·에피션스·몬디얼에 적용했고, 전 상품 태그 신규 입력으로 기록하지 않는다.
5. 저장 완료와 검색 순위 상승은 다른 결과다. 실제 검색 노출·클릭·주문 효과는 별도 측정한다.

## 남은 확인 사항

- 스마트스토어 RS: 이름·SEO 재열람 확인, 마지막 옵션 재열람은 연결중단. 저장 전 5·5·5개 확인.
- 스마트스토어 추가 34개: 저장 안내 확인 및 입력 전후 옵션 비교. 전부 재열람 확인한 상태는 아니다.
- 루가노 II 와이어의 Endurance 여부는 기존 확인 보류. SEO에 미확인 등급을 추가하지 않았다.
- 두 채널의 의미상 타입 구분은 유지했지만 모든 상품명이 문자 단위로 완전히 통일된 것은 아니다. 이후 재열람 때 최종 표기를 함께 점검한다.
