# SRAM 상품관리와 검색 최적화 운영 기준

기준일: 2026-10-13. GL&Co 공급정보와 카페24·스마트스토어를 독립적으로 대조한다. [운영 코드](management-policy.json), [공통 분류표](categories.json), [작업분류코드](../docs/YBBIKE_작업분류코드_v1.md)를 함께 사용한다.

## 상품명 만드는 기준

검색 최적화는 상품명부터 정리한다. 부품은 **브랜드 + 정확한 모델 + 세대 또는 규격 + 방향 또는 장착 방식 + 부품명** 순서로 작성하되 해당 정보만 넣는다. 카페24와 스마트스토어의 기본 상품명 및 스마트스토어 전용 상품명까지 확인한다.

- 예시: 스램 SRAM APEX 1 HRD 왼쪽 유압 브레이크 레버
- 예시: 스램 SRAM 센터라인 XR 2피스 센터락 디스크 브레이크 로터
- 단수·T-Type·AXS·장착 방식·세트 구성은 확인된 정보만 사용한다.
- 규격별 통합 상품은 특정 옵션만 제목에 넣지 않는다.
- 검색어는 모델의 한글·영문 표기와 부품 용도를 보완한다. 근거 없는 인기·호환·내일도착 표현은 넣지 않는다.
- 상품명, 검색 태그, Title, Description, 이미지 Alt는 각각 용도에 맞게 작성한다. 저장 완료와 검색 순위 상승은 구분한다.

## 실행 순서와 코드

| 코드 | 작업 | 완료 기준 |
|---|---|---|
| SRAM-PM-01 | 모델·세대·옵션·판매 단위 대조 | 동일 상품과 규격 확인 |
| SRAM-PM-02 | 소비자가·판매가·옵션 가격 대조 | 공급가와 소비자가를 구별, 충돌 값 보류 |
| SRAM-PM-03 | 재고 관리 | 본사 상태와 매장 실수량을 별도 기록 |
| SRAM-PM-04 | 판매·진열 상태 | 옵션까지 저장 상태 확인 |
| SRAM-PM-05 | 오늘출발 | 실제 매장 재고와 가능수량·마감시간 확인 |
| SRAM-PM-06 | 보류 상품 정리 | 아래 유지·삭제 기준 적용 |
| SRAM-PE-01 | 상품명 통일 | 양 채널 및 전용 상품명 확인 |
| SRAM-PE-02 | 검색정보 보완 | 관련 검색어·태그·검색 설명 저장 |
| SRAM-QA-01 | 저장 검증 | 저장 성공과 재접속 확인을 구별하여 기록 |

이 코드는 기존 PM·PE 체계에 연결되는 SRAM 세부 코드다. PM과 PE의 승인 범위와 작업 기록은 분리한다. 자동으로 쇼핑몰을 변경하는 실행기는 아니다.

## 재고와 판매 상태

- 본사 있음은 온라인 5개, 소량은 3개, 없음은 0개로 운영한다. 이는 사용자가 정한 수량이며 본사 실수량이 아니다.
- 본사 미확인은 0개로 취급하지 않는다. 매장 재고를 본사 운영 수량에 임의로 더하지 않는다.
- 카페24는 품절 옵션 판매안함, 재입고 옵션 판매함을 확인한다. 재입고 시 판매가 대체문구에 남은 품절 표시도 확인한다.
- 스마트스토어는 옵션 사용여부 Y와 진열을 유지한다. 모든 옵션이 0이어도 상품중지를 하지 않고 자동 품절로 처리한다.
- 오늘출발 가능수량은 확인한 매장 재고 범위로 설정한다. 2026-10-13 확인 상품은 기존 평일 12시 설정을 유지했으며, 이를 전 상품 공통 마감시간으로 확대하지 않는다.
- 카페24와 스마트스토어의 SRAM 연동은 해제된 상태로 보고받았다. 한쪽 저장이 다른 쪽 반영을 의미하지 않는다.

## 보류 27상품 처리 기준

사용자 결정: **매장 재고가 있으면 해당 수량만 판매하고, 없으면 삭제한다.**

| 매장 재고 확인 결과 | 처리 |
|---|---|
| 있음 | 상품 유지, 매장 수량 기준 판매 |
| 없음 확인 | 삭제 대상으로 분류 |
| 미확인 | 재고 확인 대기 |

이 결정은 2026-10-13 보류 27상품에 적용한다. 단종 증명을 별도 삭제 조건으로 추가하지 않는다. 매장 재고 목록에 없다는 이유만으로 재고 없음을 추정하지 않는다. 영구삭제가 필요한 경우 실행 도구의 최종 확인 절차를 따른다. **현재 실제 삭제는 0건이다.**

보류 사유는 동일 모델 미확인 17개, 세트 구성 미확인 7개, 규격·가격·색상 확인 3개다. 별도로 일부 옵션과 가격만 보류된 상품도 있다. 보류는 단종 확정을 뜻하지 않는다.

## 검색 누락과 모델 혼동 방지

- 한글·영문·모델번호·상품번호를 대조한다. 검색 0건만으로 미등록을 확정하지 않는다.
- APEX 레버는 검색에서 놓쳤으나 사용자가 제공한 카페24 상품 주소로 등록을 확인했다. 검색 누락 기록은 등록 확인 후 정정한다.
- 기존 Eagle과 Transmission T-Type, XG와 XS 카세트, 일반 세트와 E-MTB 세트, 체인링 마운트·오프셋·색상·치수를 구분한다.
- 단품 재고를 세트 재고로 사용하지 않는다. 본사 목록에서 빠졌다는 사실만으로 공급 종료를 확정하지 않는다.
- 가격 충돌은 확정값을 얻기 전 보류한다. 사용자 확인 가격은 근거와 적용 대상 모델을 기록한다.

## 2026년 10월 13일 작업 마감

- 카페24 MTB 분류 101개를 열거했다. 74개에 대조·반영 기록이 있고 27개는 전체 변경 보류다. 74개 모두 완전 처리됐다는 뜻은 아니며 기존 값 일치와 부분 보류를 포함한다.
- 스마트스토어 MTB 29개는 저장 또는 기존 값 일치를 확인했다. 두 채널 전체 완료로 보고하지 않는다.
- 별도 APEX 1 HRD 왼쪽 레버와 센터라인 XR 센터락 로터는 양 채널 검색 최적화 저장을 확인했다. 스마트스토어 오늘출발 가능수량을 매장 재고 범위로 설정했다.
- 보류 상품 매장 재고 확인, 삭제 실행, 스마트스토어 미매칭 상품의 상품번호 대조가 남아 있다.
- 구매자 실제 결제 테스트와 검색 노출 성과 측정은 수행하지 않았다.

## 기록과 보관

상품별 기록은 작업일, PM 또는 PE 코드, 양 채널 상품 식별자, 변경 전후, 근거, 옵션 상태, 저장 결과, 재접속 결과, 보류 사유로 구성한다. 화면 입력만으로 완료 처리하지 않는다. 연결 장애 시 저장값을 확인하기 전 변경을 반복하거나 작성 중 화면을 새로고침하지 않는다.

실제 매장 수량표, 상품별 변경 원장, 계정정보, 고객정보, 공급가와 관리자 증빙은 로컬에 보관한다. 이 저장소에는 운영 기준과 식별 가능한 비공개 정보를 제외한 작업 요약만 남긴다.
