## 관리 절차

1. 등록 확인 시 채널·상품번호·상품명·모델·세대·규격을 대조한다. 표시 상품번호와 관리자 원상품번호는 혼용하지 않는다.
2. 기존 관리코드는 유지한다. 신규 상품은 사용하지 않은 다음 코드를 부여한다. 배열 순서 변경을 이유로 코드 재부여 금지.
3. 양쪽의 정확한 상품이 확인된 경우에만 같은 행으로 연결한다. 명칭 유사성만으로 강제 연결하지 않는다.
4. 상품번호를 재사용해 다른 모델로 바꾼 경우 이전 기록을 `identity_changes`에 남기고 과거 연결·가격·재고를 승계하지 않는다.
5. 확인일과 근거를 채널별로 남긴다. 상품관리와 검색최적화 상태는 분리한다. 저장 성공 안내와 저장 후 재열람 확인도 구분한다.
6. 삭제 시 대상 상품번호·삭제 확인일·사유를 이력에 남긴다. 본사 미검색을 단종 확정이나 실제 삭제 완료로 기록하지 않는다.
7. 새로 복사 등록한 상품의 상품명·모델명·요약설명·간략설명·검색어·SEO 제목/설명·Alt에서 원본 상품 정보가 남았는지 확인한다.
8. JSON과 counts를 갱신하고 아래 명령으로 검증·열람표 재생성 후 두 파일과 관리 코드 변경분만 GitHub에 저장한다.

```sh
node sram/manage-register.cjs
node sram/manage-register.cjs --render
```

이 코드는 쇼핑몰에 접속하거나 가격·재고·옵션을 수정하지 않는다. 본사 가격·재고는 별도 최신 조회가 필요하다. 상세 관리자 증빙 및 원본 보고서는 로컬에 보존한다.
